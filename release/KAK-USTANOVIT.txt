  DotShell — как установить (без Visual Studio!)
═══════════════════════════════════════════════════════════

В этой папке:
  • DotShell.exe  — вся программа одним файлом (Windows 10/11, 64-bit).
                    Ничего дополнительно устанавливать НЕ нужно:
                    .NET уже "зашит" внутрь файла.
  • install.bat   — установка: скопирует программу в системную папку,
                    создаст ярлык в "Пуске", включит автозапуск
                    и сразу запустит остров.
  • uninstall.bat — полное удаление.

───────────────────────────────────────────────────────────
ДЛЯ ЧАТА С ИИ НУЖНА OLLAMA (ставится отдельно)
───────────────────────────────────────────────────────────
  Остров умеет разговаривать с моделью, которая работает
  на твоём компьютере. Саму программу для этого нужно
  скачать один раз:

      1) ollama.com/download  →  установить
      2) во вкладке ЧАТ нажать СКАЧАТЬ (скачает модель,
         около 1.4 ГБ, один раз)
      3) дальше всё работает без интернета и без ключей

  Если Ollama не установлена, вкладка ЧАТ покажет памятку
  с кнопкой на сайт. Всё остальное в острове работает и без неё.
───────────────────────────────────────────────────────────
ДВА АРХИВА: ЧЕМ ОТЛИЧАЮТСЯ
───────────────────────────────────────────────────────────
  • island  — только остров. Систему не трогает.
  • full    — остров + оформление всей Windows: тёмные
              заголовки окон всех программ. Ставится через
              install-full.bat, отключается галочкой в
              вкладке СИСТЕМА (или запуском --style=island).

  Вкладки в проводнике: в Windows 11 22H2 и новее папка
  открывается НОВОЙ ВКЛАДКОЙ в уже открытом окне; на
  Windows 10 вкладок нет, поэтому открывается новое окно.
  Переключается галочкой «Папки открывать вкладкой».
───────────────────────────────────────────────────────────
ВАРИАНТ 1 — установить (рекомендуется)
───────────────────────────────────────────────────────────
Двойной клик по install.bat. Готово.

───────────────────────────────────────────────────────────
ВАРИАНТ 2 — просто попробовать
───────────────────────────────────────────────────────────
Двойной клик по DotShell.exe — остров появится сразу,
без всякой установки. (Автозапуск тогда лучше включить
самим: правый клик по острову → "Запускать вместе с Windows".)

───────────────────────────────────────────────────────────
УПРАВЛЕНИЕ
───────────────────────────────────────────────────────────
  Клик по острову        раскрыть / свернуть
  Ctrl+Shift+Space       то же самое из любого места
  Ctrl+Shift+V           история буфера обмена
                         (двойной клик по записи = вставить
                          обратно в то окно, где вы работали)
  Перетаскивание         двигать остров по экрану
  Правый клик            меню: автозапуск, папка настроек, выход

  Вкладки: ЗАМЕТКИ (сохраняются автоматически), БУФЕР,
  EQ, СИСТЕМА (скрытие в полноэкранном режиме),
  ТЕМА (цвет-акцент и размер точек).

───────────────────────────────────────────────────────────
ЕСЛИ ЧТО-ТО НЕ ТАК
───────────────────────────────────────────────────────────
  • Windows Defender SmartScreen может показать "программа
    неизвестна" — это нормально для exe без цифровой подписи:
    нажмите "Подробнее" → "Выполнить в любом случае".
  • Остров пропал? Правый клик был по нему → "Выйти"?
    Запустите DotShell.exe ещё раз.
  • Ошибки пишутся в %LOCALAPPDATA%\DotShell\crash.log
  • Настройки и заметки: %LOCALAPPDATA%\DotShell\
