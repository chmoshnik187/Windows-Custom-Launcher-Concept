## Архитектура

```
DotShell.Core          — UI-независимая логика: процессы, поиск (приложения и файлы),
                         погода, курсы, настройки, обновления, аудио, время, DotMatrix
DotShell.Island.Wpf    — весь интерфейс: остров, вкладки, виджеты, окно настроек,
                         окно группы, уведомления, трей, курсоры
Windows API            — окна, реестр, акцент, звук (WASAPI), ярлыки, трей
                         (Shell_NotifyIcon), WinRT (медиа, тосты)
```

Правило, которое соблюдается: `Core` не знает про WPF; интерфейс не знает, откуда данные.
