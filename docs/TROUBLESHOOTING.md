# Если что-то пошло не так

**Главное правило:** сначала `%LOCALAPPDATA%\DotShell\crash.log`, потом вывод сборки,
и только потом догадки. Лог пишется всегда, даже если остров пропал с экрана.

Проверить, что сборка живая, можно одной командой:

```powershell
pwsh -File scripts/smoke.ps1
```

Скрипт сверяет версию, собирает проект, гоняет самопроверку и ищет `FATAL` в логе.

---

## Остров не видно

1. **Посмотри в трей.** Иконка `DotShell` — левый клик разворачивает остров.
   В Windows 11 новые значки по умолчанию попадают в переполнение (стрелка `^`).
2. **Остров утоплен за кромку.** Утащил мышью за верх экрана — снаружи остаётся только
   акцентная «ручка» высотой 2 px. Наведи мышь на верхнюю кромку по центру.
3. **Режим «не мешать».** Если на весь экран открыто чужое окно, остров сжимается в
   полоску 260×5 с акцентной линией. Наведи на неё — развернётся. Отключается в
   настройках → ОСТРОВ.
4. **Полноэкранный режим.** Игра или видео на весь монитор — остров спрятан намеренно.
   Alt+Tab и он вернётся.
5. **Вторая копия.** Программа однопроцессная: второй запуск просто выходит. Проверь
   `Get-Process DotShell`.

## Остров есть, но вкладки/виджеты пустые

- `%LOCALAPPDATA%\DotShell\settings.json` мог остаться от старой версии. Переименуй его
  в `settings.bak` и запусти заново — настройки создадутся с нуля.
- Плитки программ строятся из `pinned.json`; если пути ярлыков битые, плитка гаснет
  (прозрачность 0.38) и не запускает программу. Убери её правым кликом.

## Уведомления не появляются

- Проверь галочку **«Уведомления Windows (тосты)»** в настройках → УВЕДОМЛЕНИЯ: она
  выключает их целиком.
- Уведомление в капсуле показывается, только когда остров **свёрнут** и не утоплен.
  Если остров раскрыт, покажется карточка в правом нижнем углу — это норма.
- Тест: настройки → УВЕДОМЛЕНИЯ → **ПРОВЕРИТЬ УВЕДОМЛЕНИЕ**.

## Эквалайзер стоит на месте

Причина почти всегда одна: **loopback снимает только выбранное устройство**. Музыка
играет в наушниках, а «по умолчанию» колонки — захват видит нули.

1. Настройки → ОСТРОВ → **ЭКВАЛАЙЗЕР**, выбери устройство, куда реально идёт звук.
2. Проверь в логе: `spectrum: захват идёт, тишина 0 мс, сигнал True` — значит звук ловится.
3. Если `захват стоит`, в логе будет причина: нет устройства, занято эксклюзивно, RDP.

## Поиск не находит файл

Индексируются только **рабочий стол, документы и загрузки**, на два уровня вложенности,
до 6000 записей. Файл вне этих папок поиск не увидит — это ограничение, а не поломка.
Индекс обновляется сам раз в 10 минут; после создания файла подожди или перезапусти остров.

## Иконки стола не вернулись

Кнопка **«Вернуть иконки»** берёт пути из `%LOCALAPPDATA%\DotShell\desktop-icons\originals.json`.
Если файл удалён, вернуть автоматически нечего — остаётся правый клик по ярлыку →
Свойства → «Сменить значок» вручную. Сами ярлыки при перекраске не меняются: цель,
аргументы и рабочая папка остаются на месте.

## Трей: виджет показывает не все значки

Так и задумано, но не идеально: список собирается по скрытым окнам-приёмникам с классами
вроде `*Tray*`/`*NotifyIcon*`. Приложения с другими классами (Chrome, часть WPF-программ),
значки в переполнении и второй значок того же exe не видны. Подробнее — в
[FEASIBILITY.md](FEASIBILITY.md), раздел «Значки трея перечислить нельзя».

## Своё меню трея не открывается

Меню трея — **своё окно**, а не WPF-попап: попап с `Shell_NotifyIcon` закрывается сразу
после открытия. Если меню всё же не появляется, смотри лог: `tray: меню открыто` или
`tray: меню не открылось`. Второе — обычно следствие исключения в пункте меню.

## Чат молчит

Чат работает локально через [Ollama](https://ollama.com) — её нужно поставить один раз.

1. Проверь, что Ollama запущена: `ollama list` должен ответить.
2. Вкладка ЧАТ → **⟳** обновляет список моделей; **СКАЧАТЬ** ставит рекомендованную.
3. Ошибка «Сначала выбери модель» — модель не выбрана в списке.

## Обновление не приходит

- Проверка идёт при старте и раз в N часов (настройки → ОБНОВЛЕНИЯ).
- Нет сети или GitHub недоступен — уведомления не будет, это нормально.
- «ОБНОВИТЬ САМ» качает exe, **проверяет его версию** и подменяет при перезапуске.
  Если проверка не прошла, файл удаляется, а в логе будет
  `self-update: проверка не прошла`. Старый exe остаётся рабочим.

## Ничего не помогло

1. Закрой остров: трей → «Выйти».
2. Сохрани `%LOCALAPPDATA%\DotShell\crash.log` — по нему видно, что именно падает.
3. Приложи лог к [issue](../../issues/new/choose): что делал, что ожидал, что случилось.

## Полезные флаги для проверки

| Флаг | Что делает |
|---|---|
| `--selftest=<файл>` | самопроверка: версия, настройки, акцент, мониторы, ярлыки, апдейтер (отчёт в UTF-8) |
| `--version-probe` | печатает версию и выходит — так проверяет себя обновление |
| `--tab=home\|notes\|system\|chat\|clipboard\|shelf\|cmd` | открыть остров на нужной вкладке |
| `--settings` | сразу открыть окно настроек |
| `--launcher` | сразу открыть поиск |
| `--gallery` / `--keys` | витрина виджетов / окно клавиш |
| `--dot-demo` / `--slider-demo` | витрины размера точки и стилей ползунков (их проверяет ui-audit) |
| `--style=full\|island` | режим оформления |
| `--fake-version=0.1.0` | притвориться старой версией (проверка окна обновления) |
| `--icons-apply` / `--icons-restore` / `--icons-dir=<папка>` | монохром иконок и откат (можно на тестовой папке) |
| `--toast-test` | показать тестовое уведомление |
| `--chat-demo` | пара демонстрационных реплик в чате (снимки вёрстки) |
| `--self-update-test` | прогнать подмену exe без скачивания |

## Сборка

Visual Studio не нужна, достаточно .NET SDK 8:

```powershell
winget install Microsoft.DotNet.SDK.8
```

```bat
build.bat            :: Debug
build.bat publish    :: Release одним файлом → publish\DotShell.exe
build.bat installer  :: publish + установщик (нужен Inno Setup 6)
```

В IDE: `DotShell.sln` → startup-проект **DotShell.Island.Wpf** → платформа **x64** → F5.

Если сборка ругается на WinUI-проект `src\DotShell.Island\` — он архивный, исключи его
из решения: он не участвует в релизе.
