# Чек-лист проверки: мультимонитор и DPI (D0/D8)

Цель: подтвердить корректность геометрии, позиционирования и поведения поверхностей DotShell в конфигурациях с разными мониторами и масштабированием.

> Текущий статус среды разработки: **1 монитор, ~125% DPI** — полная матрица не закрыта. Каждый прогон помечать как `verified`, `blocked-by-env` или `fail` с логом/скриншотом.

## Области проверки

- **Остров**: позиция (верх/низ, смещение), свёрнуто/раскрыто, докинг/peek за край, drag, восстановление позиции после перезапуска, quiet/DND, уведомления в капсуле.
- **Док / Shell Bar**: сторона (лево/право), auto-hide/peek, drag/бросок к краю, сохранение `DockTop/Side`, список закрепов и индикаторы.
- **Виджеты / Desktop Host**: размещение, snap-to-grid, drag, сохранение раскладки, восстановление после перезапуска, пер-монитор раскладки (когда включено), поведение под/над окнами и без кражи фокуса.
- **Окна**: Dashboard, Control Center, Settings, Launcher/Start, ThemePicker, WallpaperSchedule — появление на ожидаемом мониторе, масштаб, клиппинг, закрытие по deactivation.
- **Системные изменения**: hot-plug/отключение монитора, смена primary, смена DPI/масштаба, смена разрешения/рабочей области, сон/пробуждение.
- **Тема/обои/гамма**: применение на правильном контексте, отсутствие «потери» окна за пределами виртуального экрана.

## Сценарии (минимум для sign-off D0/D1/D3)

1. Запуск: поверхности появляются в допустимых границах виртуального экрана, не «теряются».
2. Drag/позиционирование: остров, док, виджет можно переместить и позиция сохраняется корректно (в DIPs/привязке к монитору по принятой модели).
3. Перезапуск: позиции/раскладки восстанавливаются на том же мониторе; при отсутствии монитора — безопасный fallback на основной.
4. Изменение дисплея: `DisplaySettingsChanged`/DPI change не ломает размеры, кламп и hit-test.
5. Edge cases: отрицательные координаты виртуального экрана (монитор слева/сверху от primary), максимизация на разных мониторах, авто-hide у края.
6. Аудиты: `ui-audit`/`widget-audit`/`dock-audit` проходят последовательно на целевой конфигурации.

## Артефакты прогона

- Версия/коммит, конфигурация мониторов/DPI.
- Лог: `%LOCALAPPDATA%\DotShell\crash.log` (фрагмент релевантного времени), вывод аудитов.
- Скриншоты проблемных случаев.
- Итог: `verified` / `blocked-by-env` / `fail` + ссылка на issue/задачу.
