# Остров в панели задач: что уже есть и почему сделано так

> Короткая выжимка исследования «чистой комнатой»: что делают другие, какие у
> Windows ограничения и почему наша реализация выглядит именно так.

## Что уже делают другие

| Подход | Примеры | Суть | Почему не взяли |
|---|---|---|---|
| Дочернее окно панели | Deskband11 / Deskband11Lib | прозрачное окно парентится к `Shell_TrayWnd`, клипается по контенту, UIA следит за кнопками | автор называет это «буквально окно поверх панели»; на 26300 дети панели уходят под её XAML-композицию |
| AppBar | Seelen UI, Nexus Dock, MyDockFinder | `SHAppBarMessage` резервирует кромку экрана; панель остаётся снаружи | AppBar не умеет рисовать поверх панели задач по контракту shell |
| Инъекция в explorer | Windhawk, StartAllBack, ExplorerPatcher | хук `Taskbar.View.dll` и правка живого XAML-дерева | отдельный DLL в explorer, ломается с каждым обновлением Windows, война с антивирусом |
| Замена панели | ViGlance, Seelen UI | своё окно панели, штатная скрывается | нужно заново реализовать кнопки, трей, часы, флайауты — месяцы работы |

## Ограничение, проверенное на этой машине

Windows 11 26300 рисует панель задач через XAML/DirectComposition. Дочернее окно
`Shell_TrayWnd` создаётся, `IsWindowVisible = true`, координаты верные — но не
отображается: его закрывает композиция панели. Layered-дочернее окно тоже ведёт
себя нестабильно (виден только его контур, painter через GDI не даёт нужного кадра).
Это согласуется с отзывами про Deskband11: без инъекции в explorer «настоящего»
встраивания нет.

## Что сделано вместо этого

- `TaskbarProbe` снимает полоску панели пикселями и ищет свободный пробег между
  элементами (устойчиво к смене иконок и поиска), цвет фона берётся оттуда же.
- Свёрнутый остров ставится ровно в этот пробег, высотой в панель, с фоном —
  затемнённым акрилом панели; декор и EQ в этом режиме выключены, скругление 9.
- При скрытии панели (фуллскрин, автоскрытие) остров скрывается вместе с ней:
  поведенчески он ведёт себя как её часть.
- Раскрытие — `TaskbarBlinds`: три металлические плиты поднимаются слоями.
- Настоящий обмен: если панель не распознана (вертикальная, нестандартная) —
  верхний режим, а не исчезновение.

## Что можно добавить позже

1. Windhawk-мод, который правит XAML панели и рисует сегмент внутри неё (требует
   Windhawk у пользователя; отдельный проект, не часть exe).
2. Полная замена панели (Seelen-подобная) — отдельный большой этап.
3. Multi-monitor: сейчас сегмент только на основной панели (`Shell_TrayWnd`),
   вторичные панели (`Shell_SecondaryTrayWnd`) не обрабатываются.
